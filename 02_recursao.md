# Recursão

A função recursiva resolve um problema ao chamar-se com uma versão mais pequena do problema.

## Componentes essenciais

1. **Caso base** — condição de paragem
2. **Caso recursivo** — chamada à própria função
3. **Progresso** — garantir que se aproxima do caso base

## Cuidados

- Risco de stack overflow
- Muitas vezes existe uma versão iterativa mais eficiente
- Útil em problemas de natureza recursiva (árvores, divide-and-conquer, backtracking)
