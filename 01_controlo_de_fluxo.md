# Controlo de Fluxo

As estruturas de controlo de fluxo controlam a ordem das instruções.

## Principais estruturas

- **Condicionais**: `if`, `elif`, `else`
- **Ciclos**: `for`, `while`
- **Controlo de ciclos**: `break`, `continue`, `else` em ciclos

## Exemplos de padrões comuns

- Acumuladores
- Contadores
- Flags (variáveis booleanas de controlo)
- Early return / early exit
